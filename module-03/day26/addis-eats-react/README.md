# Addis Eats — React Static Menu

A simple static Addis Eats menu built with React and Vite as part of the React in-class exercises.

## Features

- Built with React and Vite
- Reusable `Header` component
- Reusable `Dish` component using props
- Menu rendered dynamically from an array using `.map()`
- Each dish has a unique React `key`

## How to Run

### 1. Clone the repository.

### 2. Navigate to the project folder:

```bash
cd module-03/day26/addis-eats-react
```

## 3. Install the dependencies:

```bash
npm install
```

### 4. Start the development server:

```bash
npm run dev
```

### 5. Open the local URL provided by Vite in your browser.
