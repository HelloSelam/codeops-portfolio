# Habesha Eatery Mini Site

## Overview

This project is a two-page HTML website for a fictional Ethiopian restaurant called **Habesha Eatery**.

## Pages

- **index.html** – Home page with:
  - Reservation form
  - Menu table
  - Hero image
  - Google Map

- **contact.html** – Contact page with:
  - Contact form
  - Opening hours table

## How to Run

1. Download or clone the repository.
2. Open the `day12` folder.
3. Open `index.html` in any modern web browser.
4. Use the navigation links to move between the pages.

## Accessibility Features

- Semantic HTML (`header`, `nav`, `main`, `section`, `footer`)
- One `<h1>` per page
- Properly labelled form controls
- Accessible tables with captions and column headers
- Meaningful image alt text
- Google Map iframe with a title
- Keyboard-friendly navigation
