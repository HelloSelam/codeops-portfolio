# Business Profile Card

## Business

**Bole Brew Cafe** is a fictional coffee shop located in Bole, Addis Ababa. It serves Ethiopian coffee, pastries, breakfast, and accepts TeleBirr payments.

## CSS Techniques Used

- CSS Variables (`:root` and `var()`)
- Global Reset
- `box-sizing: border-box`
- Google Fonts (Inter)
- Box Model (padding, margin, border, border-radius)
- Typography styling
- `:hover` pseudo-class
- `::before` pseudo-element
- HSL colors
