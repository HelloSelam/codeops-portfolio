# Habesha Eatery

A responsive static website for a fictional Ethiopian restaurant built using HTML and CSS. This project was created as the Week 1 project for the Software Engineering Bootcamp.

## Features

- Responsive design for mobile, tablet, and desktop
- Sticky navigation bar
- Hero section with call-to-action buttons
- About section
- Responsive menu using CSS Grid
- Reservation form with HTML validation
- Footer with contact information and business hours
- Hover effects and modern styling

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid

## Responsive Design

The website is designed using a mobile-first approach and adapts to different screen sizes.

- Mobile (360px)
- Tablet (768px)
- Desktop (1024px and above)

## Learning Objectives

This project demonstrates the use of:

- Semantic HTML
- CSS variables
- Flexbox layouts
- CSS Grid layouts
- Responsive web design
- Forms and HTML validation
- Sticky navigation
- Hover transitions
